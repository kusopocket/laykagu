機能

LayKagu は、引越しや模様替えの前に、家具の配置を 3D と 2D の図面で確かめるアプリです。

間取りを作る

  • 画像から：チラシの写真、物件サイトの間取り図の画像、PDF、書類のスキャンから、部屋の名前・帖数・寸法の文字と、壁・ドア・窓を読み取って下書きを作ります。確かめて直してから間取りにします
  • 物件ページの URL から：ページの間取り図の画像の候補と、間取り・面積・向きなどの情報を読み取ります（読み取れないサイトでは、画像を保存して取り込む方法を案内します）
  • テンプレートから：1R〜3LDK の形から始めて、寸法を直せます
  • 描いて：壁と部屋を描き、ドア・窓・キッチン・柱などの設備を置けます。下絵をなぞって作ることもできます
  • 複数の階、方位、天井の高さにも対応します

家具をそろえる

  • カタログ：124 点の家具の形から選び、幅・奥行・高さを入れるだけで形が合います。脚や取っ手は自然なまま伸び縮みします
  • 商品ページの URL から：商品名・寸法・価格・ショップ・色を読み取り、近い形を提案します
  • 写真から：家具の写真から種類と色を推定して、近い形を提案します
  • ストック：持っている家具、買う予定の家具、検討中の家具を一覧にして、予算の合計も見られます
  • Safari などの共有メニューから、商品や物件のページを LayKagu に送れます

置いて確かめる

  • 長押しで家具をつかんで、3D でも 2D でも置けます。壁に吸着し、ほかの家具とそろえられます
  • 3D は俯瞰・真上・歩いて見る視点。ミニマップで今いる場所が分かります
  • 配置チェック：家具の重なり、壁・柱との干渉、ドアの開く範囲、窓をふさぐ家具、通路の狭い所、使うためのスペースを、記号と文字で知らせます
  • 搬入経路：玄関から部屋までのドアを、大きな家具が通るかを調べます（斜めに入れる場合、分解できる家具、エレベーターや共用廊下も）
  • 窓に合わせる：カーテンなどを窓の幅と高さに合わせます

比べる

  • 配置のパターンをいくつも作り、2D を並べたり、3D の視点をそろえたりして比べられます。違いの印と、通路の幅や問題の数の比較表も出します

書き出す・共有する

  • 配置図と家具リストを PDF（A4・A3、縮尺 1:50・1:100 を自動で選びます）、PNG、CSV に書き出せます
  • プロジェクトをファイル（.laykagu）にして、家族の端末で開けます
  • iCloud 同期で、自分の iPhone と iPad で同じプロジェクトを使えます

だれでも使いやすく

  • VoiceOver だけで、間取りの作成から配置・チェック・書き出しまでできます
  • 文字の大きさ、コントラストを上げる、視差効果を減らすに対応します
  • iPhone Duo では、開いても閉じても編集の状態を保ち、開いた画面では 3D と 2D を並べて使えます

表示される寸法や判定は目安です。家具の購入や搬入は、実物を測って確かめてから決めてください。
